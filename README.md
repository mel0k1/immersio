# Immersio

Десктопный музыкальный плеер на Rust + Tauri + React.

Стриминг YouTube Music, локальные файлы, синхронизированные тексты от LRCLIB, очередь, плейлисты, любимые треки и полноэкранный плеер с подсветкой строк.

## Возможности

- Поиск по каталогу YouTube Music: треки, видео, альбомы, артисты, плейлисты
- Страницы альбомов, артистов и плейлистов с размытым фоном в цвет обложки
- Потоковое воспроизведение через прокси Tauri с поддержкой Range; при блокировке — fallback на встроенный плеер YouTube
- Локальная медиатека: импорт файлов и папок, чтение тегов и обложек, копия хранится в данных приложения
- Тексты с активной строкой и перемоткой по клику
- Очередь, перемешивание, повтор, лайки, свои плейлисты, сохранение альбомов и артистов
- Горячие клавиши и MediaSession
- Интерфейс на русском и английском, настраиваемый акцент

## Сборка

```bash
npm install
npm run tauri dev
npm run tauri build
```

Нужны Rust 1.77+ и системные зависимости Tauri (на Linux — webkit2gtk-4.1).
