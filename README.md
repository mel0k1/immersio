# Immersio

[![CI](https://github.com/mel0k1/immersio/actions/workflows/ci.yml/badge.svg)](https://github.com/mel0k1/immersio/actions/workflows/ci.yml)

Десктопный музыкальный плеер на Rust + Tauri + React.

Стриминг YouTube Music, локальные файлы, синхронизированные тексты от LRCLIB, радио, очередь, плейлисты и полноэкранный плеер.

## Возможности

- Поиск по каталогу YouTube Music: треки, видео, альбомы, артисты, плейлисты
- Поиск по SoundCloud: результаты влиты в общий список по релевантности (двойники убираются), отдельная вкладка, прямое воспроизведение (MP3/AAC), радио и лайки
- Страницы альбомов, артистов и плейлистов с размытым фоном в цвет обложки
- Потоковое воспроизведение через прокси Tauri с поддержкой Range; выбор качества; при блокировке — fallback на встроенный плеер YouTube
- Радио по треку через innertube: вручную из очереди или автопродолжение в конце очереди
- Тексты с активной строкой, перемоткой по клику и ручным сдвигом времени
- Караоке-подсветка по словам: настоящие пословные тайминги из YouTube-субтитров, когда они доступны; иначе плавная заливка слов внутри строк LRCLIB
- Отсчёт между строками текста во время длинных инструментальных пауз
- Живой WebGL-фон в полном плеере, развивающийся из обложки (отключается в настройках)
- Следующий трек предзагружается заранее: переключение почти мгновенное
- Скорость воспроизведения 0.75–2× с сохранением тона
- Офлайн-кэш: прослушанные потоки сохраняются на диск и работают без сети (лимит настраивается: 1/3/10 ГБ или без лимита, старые файлы вытесняются)
- Плавающий мини-плеер вторым окном Tauri: всегда поверх окон, синхронизация через события
- Импорт плейлистов по ссылке: YouTube Music, YouTube-плейлисты, Spotify (embed), Deezer (публичный API), SoundCloud (без ключей) — треки автоматически ищутся в YouTube Music
- Скачивание трека в выбранную папку (сохранение через системный диалог)
- Эквалайзер: пять полос (60 Гц … 14 кГц) на Web Audio для потоков
- Светлая и тёмная темы
- Проверка обновлений прямо в приложении (Настройки → О программе): при выходе новой версии скачивает и устанавливает её сам — без похода на GitHub
- Cookie YouTube в настройках: снимает проверку «подтвердите, что вы не бот» на сетях, где YouTube требует вход
- Локальная медиатека: импорт файлов и папок, drag&drop прямо в окно, чтение тегов и обложек
- Очередь с перетаскиванием, сохранением в плейлист, перемешиванием и повтором
- Лайки, свои плейлисты, сохранение альбомов и артистов, копирование ссылок на треки
- Discord Rich Presence работает сразу после установки; при желании можно подменить Application ID своим приложением
- MPRIS на Linux: трек и управление видны в системных виджетах и оболочках KDE/GNOME
- Очередь восстанавливается при запуске вместе с позицией трека
- Таймер сна: пауза через 15/30/60 минут, до конца трека или кнопкой в мини-плеере
- Пауза при подключении нового аудиоустройства (отключается в настройках)
- Позиция и размер окон (включая оверлей) сохраняются между запусками
- Горячие клавиши перенастраиваются прямо в настройках, MediaSession и баннер при потере сети
- 13 акцентов: иконка окна и таскбара перекрашивается в выбранный цвет на лету
- Интерфейс на 11 языках, настраиваемый акцент

## CI

`ci.yml` проверяет фронтенд и `cargo check --workspace` на Linux, Windows и macOS.
`release.yml` собирает и публикует инсталляторы (deb, rpm, AppImage, msi, nsis, dmg) на тег `v*`.

## Сборка

```bash
npm install
npm run tauri dev
npm run tauri build
```

Нужны Rust 1.77+ и системные зависимости Tauri (на Linux — webkit2gtk-4.1).
